# 开源项目研究记录

V1.2 对公开 GitHub 项目进行了结构研究，但没有直接复制没有明确许可证的项目代码。

## 重点参考

### xixicc186/xixicc2027
- 定位：2027 届秋招信息聚合。
- 值得借鉴：行业分类、批次/届别、截止时间、首次出现/最后出现、交叉确认次数、Agent Skill、每日更新思路。
- 仓库页面未发现 LICENSE 文件，因此本项目不直接复制其代码或批量再发布其 jobs.json 数据。
- 参考： https://github.com/xixicc186/xixicc2027

### h46373824-tech/offerPilot-AI
- 定位：2027 届求职工作台。
- 值得借鉴：岗位检索、收藏、投递、面试、Offer、校招日历、数据核验等工作流。
- 许可证：Apache-2.0。
- 参考： https://github.com/h46373824-tech/offerPilot-AI

### mengxi111/career-agent
- 定位：AI 校招情报、岗位抓取、匹配分析与投递管理。
- 值得借鉴：GitHub Actions 定时任务、多源抓取、标准化、增量分析、静态报告、通知。
- 许可证：MIT。
- 参考： https://github.com/mengxi111/career-agent

### Bynlk/JobHunter
- 定位：多平台实习/校招聚合、爬虫、筛选、导出。
- 值得借鉴：数据源分层、API/网页采集、统一字段、URL 去重、统计与导出。
- 许可证：MIT。
- 参考： https://github.com/Bynlk/JobHunter

## 本项目 V1.2 的原则

1. 学架构，不盲目复制。
2. 有明确开源许可证时才考虑复用代码，并保留许可证与版权声明。
3. 招聘数据优先来自允许公开使用、企业官方入口或已授权的数据源。
4. 第三方项目的岗位数据不默认视为可以复制、商业化再发布。
5. 页面展示的每条真实岗位都应保留来源和原始链接。
