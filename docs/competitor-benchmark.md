# 竞品/参考网站对比（2027秋招雷达）

## 参考对象

| 平台 | 规模/特点 | 强项 | 我们应该吸收什么 | 不直接照搬什么 |
|---|---|---|---|---|
| 秋招网 | 页面展示约 5,500 当前岗位、14,000+累计岗位 | 公司/岗位/城市/批次/企业性质筛选 | 多维筛选、截止时间、更新排序 | 不把第三方聚合数据直接当官方事实 |

## 我们的定位

不是做“另一个岗位列表”，而是做**可核验的秋招数据层 + 求职决策工具**：

1. 聚合：官方校招 + 合法公开聚合信源。
2. 标准化：公司、岗位、城市、行业、批次、学历、发布时间、截止时间统一字段。
3. 去重：同公司/岗位/城市/届次跨来源合并。
4. 核验：保留 source_url、last_verified、confirmed_by。
5. 新鲜度：区分 active / pending_review / expired / source_entry。
6. 决策：后续加入画像匹配、截止风险、岗位相似度、投递记录。

## 当前明确的优化方向

- 不再用虚构的 2099-12-31 代替未知截止时间。
- 收藏 ID 全部按字符串处理，避免新岗位 ID 被转成 NaN。
- 信源中心从硬编码逐步改为读取 company_sources.json。
- 下一阶段优先把可公开访问且结构稳定的官方站做成 source-specific parser。
- 第三方聚合站先作为“发现源”，最终岗位事实尽可能回链官方页面。
