# 2027秋招雷达

一个面向 2027 届毕业生的全专业招聘信息聚合与投递管理网页。

## V1.1 已上线

公网地址：<https://qq1739825911-web.github.io/2027-qiuzhao-radar/>

本次升级重点不是“把页面做漂亮”，而是把它从一个招聘信息展示页，升级成真正可继续扩展的**求职工作台**：

- 岗位库：公司 / 岗位 / 专业 / 城市 / 企业类型 / 学历 / 截止时间 / 来源 / 核验时间
- 多条件筛选：关键词、岗位类别、城市、企业类型、招聘状态
- 收藏：浏览器本地保存
- 投递看板：收藏 → 已投递 → 笔试 → 面试 → Offer / 淘汰
- 求职画像：专业、技能、城市、学历，本地保存，为后续 AI 匹配做准备
- 信源中心：集中管理招聘入口
- 数据规范：单独的 `data/jobs.json`，便于后续自动同步
- 数据校验：`scripts/validate_jobs.py`，为后续自动化更新做基础

## 重要的数据原则

现在页面中的“牛客 / 应届生求职网 / BOSS直聘”等条目是**招聘入口/演示数据**，不是声称已经抓取这些平台的全部岗位。

真正的岗位库必须至少保留：

`company`、`title`、`category`、`city`、`degree`、`publish_date`、`deadline`、`source`、`source_url`、`last_verified`、`status`

后续接入数据时还需要做：

1. 来源采集
2. 字段标准化
3. 重复岗位合并
4. 截止时间判断
5. 原始链接检查
6. 最后核验
7. 失败源监控
8. 每日增量更新

只接入公开、允许使用或已获授权的数据源，不绕过招聘网站的登录、验证码或访问限制。

## 项目定位

这个项目最终不是“又一个招聘网页”，而是：

**招聘数据层 + 岗位搜索 + AI 匹配 + 投递管理 + 秋招信息提醒。**

这也是这个项目作为个人作品集项目最有价值的地方。

## V1.2：数据层正式搭起来

这一版开始把项目从“前端页面”往“招聘信息产品”推进：

- `docs/research-and-licenses.md`：记录参考的开源项目与许可证边界

但不会直接把没有明确许可证的第三方代码或岗位数据库整包复制进来。V1.2 采用“研究架构 → 自己实现”的方式；对于 MIT/Apache-2.0 项目，未来如直接复用代码，会保留对应许可证和版权声明。

### 下一步 V1.3

V1.2 先把数据结构和自动维护底座搭好。下一步才开始接真正的数据采集器：

**官方招聘页 / 允许使用的公开数据源 → 采集器 → inbox → 标准化 → 去重 → 过期判断 → 人工/规则核验 → jobs.json → GitHub Pages**
